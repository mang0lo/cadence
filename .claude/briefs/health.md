# Feature: health (F = health) — make every imported metric explorable
Existing stubs: HealthPage ('/health'), SleepPage, HeartPage, BodyPage ('/health/sleep|heart|body'), ExplorerPage ('/health/explorer'), MetricPage ('/health/explorer/:type'), EcgPage ('/health/ecg'), widget `HealthSnapshotWidget`. Core endpoints: `GET /api/metrics/types` (count, first/last ts, aggregation 'sum'|'avg'|'duration'), `GET /api/metrics/daily?metric=&fromDay=&toDay=` (metric = HK identifier; category metrics '<identifier>:<value>' in minutes; sleep attributed to the wake-up day), `GET /api/metrics/samples?type=&from=&to=&limit=&order=`. Tables: records, record_types, record_type_stats, daily_metrics, activity_summaries, correlations, ecg_readings (gunzipFloat32 from apps/server/src/lib/gzip.ts), health_items, athletes. Server under `/api/health`, DTOs in packages/shared/src/features/health.ts.

1. **Catalogue**: HK identifiers → en/de names, category (Activity, Heart, Respiratory, Vitals, Body, Sleep, Mobility, Hearing, Nutrition, Mindfulness, Cycle tracking, Symptoms, Other), display unit/format (fractions → %, HRV ms, bpm, kg/lb, kcal, m → km/mi, minutes → h:mm), "up is good". ~150 common identifiers; unknown → prettified identifier.
2. **Overview ('/health')**: cards for key metrics present in the data (resting HR, HRV, VO2max, walking HR, respiratory rate, SpO2, wrist temperature, weight, body fat, steps, active energy, exercise minutes, sleep, mindful minutes, daylight): latest, 30-day avg vs previous 30 days with correctly signed Delta, sparkline, links.
3. **Sleep**: derive step → nights from HKCategoryTypeIdentifierSleepAnalysis (merge overlaps, prefer the best staged source per night, InBed vs Asleep*/Core/Deep/REM/Awake, naps separate, midnight/timezones): bedtime, wake, in bed, asleep, minutes per stage, efficiency, awakenings. Charts: nightly stacked stages (30/90 nights), duration trend + 7-day avg + goal line, bedtime/wake consistency, hypnogram for a selected night, that night's HR/HRV/respiratory rate/wrist temperature.
4. **Heart**: resting HR, HRV, walking HR, HR recovery, daily HR range (min–max band + avg), VO2max — one chart each; high/low/irregular notifications; intraday HR for a chosen day.
5. **Body**: weight with 7-day average and monthly change, BMI, body fat, lean mass, height; blood pressure from correlations.
6. **All data ('/health/explorer')**: searchable, categorised list of every record type (count, first/last date, sparkline) + counts of other items (activity summaries, ECGs, audiograms, clinical records, correlations). **Metric page**: day/week/month aggregation, chart (sum bars / avg line with min–max band / category minutes stacked by value), statistics, source breakdown, paginated raw samples, intraday view.
7. **ECG ('/health/ecg')**: recordings list (date, classification, avg HR) + waveform on ECG paper (25 mm/s, 10 mm/mV, light-red grid), horizontal scrolling, SVG or canvas 2D.
8. **Widget** `HealthSnapshotWidget`: resting HR, HRV, last night's sleep, today's steps with sparklines.
Unit-test the sleep-night builder (overlaps, multiple sources, naps, midnight, time zones).
