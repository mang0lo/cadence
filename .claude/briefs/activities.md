# Feature: activities (F = activities) — the heart of the Strava experience
Existing stubs: HomePage ('/'), ActivitiesPage ('/activities'), ActivityPage ('/activities/:id'). Core endpoints: `GET /api/workouts` (filters, paging, sort), `GET /api/workouts/:id` (WorkoutDetail incl. splits, best efforts with rank, HR zones, events, stats, meta), `GET /api/workouts/:id/streams` (t, lat, lon, ele, dist, speed, hr, cadence, power, moving), `PATCH /api/workouts/:id`, `GET /api/workouts/:id/gpx?lang=`, `GET /api/meta/sports`, `GET /api/athlete`.

1. **Dashboard ('/')** — Strava-like three columns on wide screens (stacked on narrow). Left: athlete card (name, all-time and this-year totals for the main sports, this week's mini bar chart, link to settings). Centre: activity feed — cards with sport icon, title, date/time + relative time, sport-specific key stats (distance, pace/speed, time, elevation, effort, avg HR), RouteThumbnail, medal badges for best efforts ranked 1–3, notes excerpt; "load more"; click → detail. Right: other features' widgets in this order — `WeeklySnapshotWidget`, `FitnessWidget` ('../progress/widgets'); `StreakWidget`, `GoalsWidget`, `CalendarWidget` ('../consistency/widgets'); `HealthSnapshotWidget` ('../health/widgets'); `ExplorerWidget` ('../maps/widgets'). They may be stubs returning null — just place them (each renders its own Card). Empty state with an "Import data" CTA (link /import) when there are no workouts.
2. **Activities list ('/activities')** — filter row (sport chips with counts from /api/meta/sports, date-range presets + custom, text search, "with GPS" toggle), sortable table on wide screens / cards on narrow (date, title, sport, distance, time, pace/speed, elevation, avg HR, effort), totals for the filter, pagination, quick actions (hide/unhide, change sport). Filters in URL search params.
3. **Activity detail ('/activities/:id')** — the showpiece:
   - Header: inline-editable title (PATCH name; falls back to workoutTitle), sport selector, date/time in the activity's local time + timezone, device/source, editable notes, hide, GPX download, "Create segment" link to '/maps/segments/new?workout=:id' (built by the maps feature), prev/next navigation.
   - Hero stats tailored by sport (run: distance, moving time, pace, elevation, effort, calories; ride: speed, power; swim: pace/100 m, strokes, laps; gym/yoga: duration, HR, calories) + secondary stats.
   - **Map with playback (top user priority)**: BaseMap route (casing + line), start/finish markers, km/mi markers; route coloring plain / pace / heart rate / elevation grade / HR zones (`gradientExpression` from streams, with a legend). Playback: play/pause, speed 1× … 300× plus "whole activity in ~30 s", scrubber timeline showing pauses, moving athlete marker with heading, travelled part highlighted, live readout (elapsed, distance, pace/speed, HR + zone, elevation, cadence, power). Camera: overview / follow / **3D flyover** (terrain on, pitch ~60°, bearing following the course, smooth easing). Keyboard: space, ←/→, +/-. Smooth: precompute arrays, interpolate, update sources at most once per frame.
   - Charts synced with the map: elevation (area), pace/speed, HR (zone bands), cadence, power — stacked, shared x-axis (distance vs time toggle); hover → map marker + crosshair on all charts; playback playhead; brush a range → highlight on map + stats of that section.
   - Splits (km/mi) with pace bars, HR, elevation; laps from events; HR-zone distribution; best efforts with PR/2nd/3rd medals; analysis cards: aerobic decoupling, efficiency factor, grade-adjusted pace, climbs (length, gain, avg grade, VAM), pace/HR histograms.
   - "Compared with similar activities": pace (and HR) trend of similar efforts with this one highlighted and its rank.
   - Indoor / no-GPS workouts: no map, but stream charts and all stats.
4. **Server** (`/api/activities`, DTOs in packages/shared/src/features/activities.ts): `GET /summary` (athlete card totals), `GET /:id/similar`, `GET /:id/analysis` (computed from streams; cache keyed by workout id + derived_version). Unit-test the analysis math.
