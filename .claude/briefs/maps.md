# Feature: maps (F = maps) — exploration on the map
Existing stubs: HeatmapPage ('/maps/heatmap'), ExplorerPage ('/maps/explorer'), RoutesPage + RoutePage ('/maps/routes', '/maps/routes/:id'), SegmentsPage + SegmentPage ('/maps/segments', '/maps/segments/:id'), widget `ExplorerWidget`. Add '/maps/segments/new' (query `?workout=:id`; linked from the activity page). Server under `/api/maps`, DTOs in packages/shared/src/features/maps.ts. Geo helpers in apps/server/src/lib/geo.ts (haversine, bearing, destination, cumulativeDistance, bounds, simplifyIndices/simplifyPath, encodePolyline/decodePolyline, distanceToPath); full tracks via getStreams().

1. **Personal heatmap**: all GPS routes as glowing lines (stacked low-opacity / blurred line layers so frequent streets get brighter), dark basemap by default, filters (sport, year/period), color themes (hot / blue / purple), optional point density, click → activity popup. **Time-lapse**: animate the period's activities drawing in chronological order with date overlay, play/pause/speed.
2. **Explorer tiles**: derive step → zoom-14 slippy tiles each workout passed through (interpolate gaps) with first visit / count / first workout; page: visited squares, max cluster (visited tiles whose 4 neighbours are visited), max square (largest n×n), totals, new tiles per month; optional zoom 17.
3. **Routes**: derive step clusters same-sport GPS workouts following the same course (start & end within ~200 m + path similarity on ~50 resampled points scaled by length; reversed direction = separate route), incremental. Routes page: cards with RouteThumbnail, auto name (start area + distance; renameable), times done, best time, trend sparkline. Route detail: map, efforts table (date, time, pace, avg HR, rank), **time-trend chart (improvement on a fixed course)**, best vs latest.
4. **Segments**: create on '/maps/segments/new?workout=:id' (map + two-handle range selector along the route with live distance/elevation/grade, name); match ALL GPS workouts of compatible sports (near start, then end, in order, following within tolerance; interpolated crossing times; avg HR, pace) and new ones via a derive step. List (starred first) with distance, avg grade, efforts, PR; detail: map + elevation profile, personal leaderboard, trend chart, rename/star/delete.
5. **Widget** `ExplorerWidget`: tiles count, max square, new tiles this month, link.
Unit-test the geometry (tile cover incl. gaps, max square/cluster, route similarity incl. reversed, segment matching).
